Allow your microphone

Chrome needs your permission before BYOA can transcribe your voice on this device.

This step briefly opens the microphone to request access, then immediately releases it. Nothing is recorded, saved, or uploaded.

Choose Allow microphone, then approve Chrome’s prompt.

Local language pack

Check availability, then download if needed. Downloads require this button click.

If access is blocked

  1. In Chrome’s microphone settings, allow microphone access for BYOA. Check that the correct microphone is selected.
  2. On Mac, open System Settings → Privacy & Security → Microphone and enable Google Chrome. Restart Chrome if asked.
  3. Return here and try Allow microphone again.

Once access is allowed, return to your original tab and use the mic button in the BYOA sidebar or on the connected site. You can review the transcript before sending it.
